# SLR(1) Parser & Parse Tree Visualizer

A fully dynamic Compiler Design project built with **React**, **Vite**, and **Tailwind CSS**. It computes First/Follow sets, LR(0) items, and generates Action & Goto parsing tables on the fly for any custom context-free grammar.

## Features
1. **Fully Dynamic SLR(1) Engine**: Automatically parses custom CFGs, computes First & Follow sets, generates LR(0) states, and builds Action & Goto tables dynamically.
2. **Step-by-Step Playback**: Play, pause, step forward, step back, and adjust animation speed.
3. **Parse Stack Visualizer**: Real-time visualization of state and symbol stack transitions.
4. **Parse Tree Visualizer**: Bottom-up syntax tree rendering with node merging animations.
5. **Interactive Parsing Table**: Inspect dynamically computed Action & Goto tables with active cell highlighting.
